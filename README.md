# Santilé — E-commerce de Cajas de Alimentos

**Demo funcional de e-commerce** para comercialización de productos locales en cajas temáticas.

## 🎯 Características del Demo

- ✅ Catálogo completo con 5 categorías de productos
- ✅ Carrito de compras con controles de cantidad
- ✅ Checkout en 3 pasos (entrega, pago, confirmación)
- ✅ Gestión de cuenta (direcciones, historial de órdenes)
- ✅ Diseño responsivo (mobile/tablet/desktop)
- ✅ Tema claro y oscuro
- ✅ Sin dependencias externas (vanilla HTML/CSS/JS)

## 🚀 Deployment

Accede al demo en vivo en:
**[santile-demo.vercel.app](https://santile-demo.vercel.app)** (próximamente)

```
index.html   # Single Page App completa (1338 líneas)
  ├── Styles    (CSS con tokens, componentes, layouts)
  ├── Markup    (HTML semántico)
  └── Scripts   (JavaScript vanilla para routing y estado)
```

## 🛒 Categorías

- **Cárnicos** — Productos cárnicos variados
- **Alimentos** — Alimentos gourmet y básicos
- **Aceite y Condimentos** — Aceites premium y especias
- **Dulces** — Postres y confitería
- **Galletas** — Galletas artesanales
